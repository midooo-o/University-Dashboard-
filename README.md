University Analytics Dashboard

This project is a web-based analytics dashboard built using **Flask**.  
It visualizes university-related data in an interactive and user-friendly way.

The application is deployed online and can be accessed through a public link without any local setup.


🚀 Features
- Interactive dashboard for data visualization
- Built with Flask (Python)
- Uses HTML templates for the frontend
- Deployed online using Render
- Accessible from anywhere via a web browser

🛠 Technologies Used
- Python
- Flask
- Gunicorn
- HTML / CSS
- SQLite Database
- Render (Cloud Deployment)
